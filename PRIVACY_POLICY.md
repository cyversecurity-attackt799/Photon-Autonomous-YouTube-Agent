# Privacy Policy — Photon Autonomous Agent

**Last updated:** October 17, 2026

Photon Autonomous Agent is a locally developed tool intended to support YouTube content research and planning.

## Information Collection

The project is designed to use information requested through the YouTube Data API for its intended research and planning functions. The developer does not intentionally collect personal information from users through a public-facing service.

## YouTube API Services

Photon uses YouTube API Services to access YouTube data. Use of YouTube API Services is subject to the YouTube Terms of Service and Google Privacy Policy.

Google Privacy Policy: https://policies.google.com/privacy

YouTube Terms of Service: https://www.youtube.com/t/terms

## Data Storage and Security

API credentials must be stored securely and must not be published in source code or public repositories. Any data stored locally is handled by the developer operating the tool.

## Third-Party Services

The tool may interact with Google and YouTube services. Those services are governed by their own terms and privacy policies.

## Contact

For privacy-related questions, contact the project developer through the contact information provided in the project's public repository.
